# Observatory

A private, offline keeping of moons, blooms and stars. Everything is stored only on your own device.

- Open the published page in Safari and use Share > Add to Home Screen.
- Use Book > Keepsakes to save and restore backups. Never commit backup files here.
- After uploading a new `index.html`, change `VERSION` in `sw.js` (for example `observatory-v2`) so phones pick up the update.
